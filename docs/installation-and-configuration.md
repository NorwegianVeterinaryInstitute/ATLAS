# Installation
To install ATLAS, clone the repository to a location on your system:

```
git clone git@github.com:NorwegianVeterinaryInstitute/ATLAS.git
```

Optional: The scripts may be linked to a `bin` directory on your system to make it easy to use them!

# Dependencies
ATLAS is written with GNU bash, version 5.1.8(1)-release (x86_64-redhat-linux-gnu).
Additionally, the following dependencies are required:
- `rsync` >= v3.2.5
- `sha512sum` >= v8.32
- `dos2unix` >= v7.4.2

# Configuration
ATLAS' paths and variables are set with a configuration file. The scripts assume this file is located in `$HOME/.config/atlas/config.sh`. Users can also set an alternative path by setting an `XDG_CONFIG_HOME` variable, pointing to a directory containing `atlas/config.sh`. An example config file can be found in the `etc` directory in this GitHub repository.
The file must contain values for the following variables:

```
# Directory paths
PROJ_DIR="<path>"
ACTIVE_DATA_DIR="<path>"
FREEZE_DIR="<path>"
ARCHIVE_DIR="<path>"
TEMPLATE_DIR="<path>"
ARCHIVE_SIZE_THRESHOLD_GB="value"
```

Variable explanations:
- `PROJ_DIR`: The directory where the project directories are generated by `create_project.sh`
- `ACTIVE_DATA_DIR`: The directory where activated data is sent to by `activate_data.sh`
- `FREEZE_DIR`: The directory where studies are temporarily frozen by `freeze_study.sh`
- `ARCHIVE_DIR`: The directory where studies are archived by `archive_study.sh`
- `TEMPLATE_DIR`: The directory that holds the various README templates used in ATLAS
- `ARCHIVE_SIZE_THRESHOLD_GB`: The maximum allowed size of a study (in gb) in `archive_study.sh` without the script throwing a warning
