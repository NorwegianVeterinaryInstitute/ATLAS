ATLAS (Automated Transfer, Logging, Archiving, and Structures), is a workflow concept for managing sequencing- and analysis data. The scripts ensures safe transfer, logging, and archiving of studies, enabling better collaboration, structure, and reproducibility. Please check the Wiki for more information!
