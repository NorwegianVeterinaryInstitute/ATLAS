ATLAS (Automated Transfer, Logging, Archiving, and Structures), is a workflow concept for managing sequencing- and analysis data. The scripts ensures safe transfer, logging, and archiving of studies, enabling better collaboration, structure, and reproducibility. Please check the [documentation](https://norwegianveterinaryinstitute.github.io/ATLAS/) for more information!

## Citing ATLAS

ATLAS is developed at the [Norwegian Veterinary Institute](https://ror.org/05m6y3182) (ROR: `05m6y3182`).

If you use ATLAS, please cite it. Citation metadata is in [CITATION.cff](CITATION.cff); use the "Cite this repository" button on GitHub to get APA or BibTeX.
